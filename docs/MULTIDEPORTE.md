# Reglas de apuestas sobre eventos reales

Todos los encuentros, resultados y cuotas visibles proceden de proveedores deportivos. Los boletos utilizan créditos virtuales, sin depósitos ni premios canjeables.

| Deporte | Mercados compatibles cuando hay cuotas | Resultado para liquidar |
| --- | --- | --- |
| Fútbol | 1X2, doble oportunidad, goles 1.5/2.5, ambos anotan | Tiempo reglamentario verificado, sin prórroga ni penaltis |
| Baloncesto | Ganador sin empate, puntos totales 215.5 | Marcador final, incluida la prórroga |
| Béisbol | Ganador, carreras totales 8.5 | Final, incluidas entradas extra; un empate oficial anula el ganador |
| F1 | El proveedor actual no publica cuotas | Solo calendario y clasificación real |

La compatibilidad de un mercado no garantiza que el proveedor lo ofrezca. La aplicación no transforma una cuota de otra línea o período. En F1 se conservan los modelos de clasificación para resultados, sin precios de apuestas fabricados.

Un parlay combina hasta diez eventos distintos. Las cuotas se multiplican con precisión decimal y el retorno se trunca a dos decimales. La interfaz muestra hasta seis decimales de cuota total y señala una aproximación con ≈ cuando corresponde.

No se aceptan selecciones si el mercado cierra, cambia la cuota o el evento ya comenzó. Las cuotas caducadas se bloquean. El servidor comprueba saldo, identidad e idempotencia antes de descontar créditos.

Los resultados no verificados o incompletos permanecen pendientes. La anulación de un evento elimina su cuota del parlay; si todos se anulan, se devuelve el importe. No existe una pantalla para decidir resultados manualmente.

La consulta pública y la cuenta iniciada se basan en el mismo catálogo real. Los favoritos y boletos se sincronizan con el reloj. Los antiguos registros de práctica quedan fuera de las pantallas y de las respuestas de resultados.
