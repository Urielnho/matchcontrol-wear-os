# Presentar MatchControl 2.0

1. Ejecuta mobile en el teléfono y wear en el reloj circular. Explica que son dos aplicaciones del mismo proyecto.
2. Sin sesión, muestra la etiqueta DEMO, el saldo educativo, un partido y sus mercados. Confirma un boleto y reinicia la app para demostrar persistencia.
3. En Perfil, el laboratorio DEMO permite resolver eventos ficticios y comprobar la liquidación sin cambiar encuentros reales.
4. Inicia sesión con tu cuenta. Muestra partidos reales, favoritos y la separación del saldo local. Si faltan cuotas, muestra el estado vacío; no inventes cobertura.
5. Explica que Supabase controla la contabilidad y API-Football entrega los datos deportivos. Las credenciales privadas permanecen en el servidor.
6. Presenta las pruebas y capturas de `ESTADO-2.0.md`. Distingue las pruebas instrumentadas de la comprobación pendiente de dispositivos vinculados.
7. Para el intercambio real, vincula teléfono y reloj desde Device Manager → Pair Wearable. Después verifica favoritos, envío de partido, saldo y reconexión. Esta comprobación aún queda pendiente en la entrega actual.

Todos los boletos usan créditos virtuales. No hay depósitos ni premios canjeables.
